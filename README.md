# 智慧校园点餐

## 📖 项目描述

本项目是一个专注于校园内部餐饮预订、外卖配送与食堂档口在线交易的高并发点餐平台。系统深入解决了在真实校园就餐高峰期（如下课放学后的瞬时流量洪峰）、特价菜品秒杀等极高并发场景下，面临的超卖、缓存数据一致性等复杂分布式架构难题。

在常规的食堂档口信息展示、菜品评价与浏览功能之上，本项目重点针对**核心交易链路（如特价菜秒杀下单、库存扣减、复杂订单状态流转）**进行了企业级架构的重构与深度优化。通过引入一系列成熟的中间件与分布式技术，构建了高性能、高可用且具备严格数据一致性的现代化后端架构。

---

## 🛠 技术栈

### 核心框架 & 存储
- **基础框架**: Spring Boot 2.3
- **持久层框架**: MyBatis-Plus
- **关系型数据库**: MySQL 8.x
- **分布式缓存**: Redis

### 高并发 & 分布式组件
- **分布式锁 & 并发控制**: Redisson
- **消息中间件**: RocketMQ / RabbitMQ
- **数据一致性组件**: Alibaba Canal
- **状态机引擎**: COLA StateMachine
- **熔断与限流**: Alibaba Sentinel

---

## 🚀 核心架构与技术亮点

### 1. 极致性能的秒杀交易架构
基于 **Redis Lua 脚本**原子化完成库存预扣与资格校验，结合 **RocketMQ** 异步解耦订单创建流程，解决秒杀（如限量特价套餐）瞬时高并发超卖问题，将核心接口 QPS 从 2000 提升至 8000+（提升 4 倍）。

### 2. 秒级实时的延迟任务处理
引入 **RocketMQ 延迟消息**替代数据库定时扫描，将订单超时关闭的实时性从分钟级提升至秒级，同时数据库 CPU 负载从 85% 下降至 8% 以下。通过消息重试和幂等校验，确保百万级订单场景下库存准确无误。

### 3. 金融级双重并发控制机制
结合 **Redisson 分布式锁**粗粒度前置拦截与 **MySQL 乐观锁**细粒度底层兜底，解决支付回调与超时关单任务的并发竞态问题，有效避免高并发下大量无效的数据库自旋。

### 4. 基于 COLA 状态机的生命周期管理
针对校园外卖、堂食自提等复杂订单生命周期，引入 **COLA 状态机**重构核心状态流转链路，保障支付、出餐核销、退款等核心节点流转的安全与可维护性。

### 5. 稳健的缓存一致性自动化闭环
针对档口及菜品信息变更场景，整合 **Canal** 监听 MySQL Binlog 异步触发缓存淘汰，配合 MQ 指数退避重试与死信队列告警，构建了缓存与数据库最终一致性的自动化闭环。

### 6. 高可用热点缓存防御体系
基于 **Redis 缓存**支撑热点菜品查询，采用**布隆过滤器 + 空对象缓存**防御穿透，**热点预热 + 随机 TTL** 规避击穿与雪崩，就餐高峰期（如大促期间）核心接口响应稳定在 50ms 内。
